1. Subir o PostgreSQL 
 
Objetivo: iniciar o servidor PostgreSQL local do MercaSys. 
 
"C:\Program Files\PostgreSQL\18\bin\pg_ctl.exe" -D "C:\PostgreSQLData" -l "C:\PostgreSQLData\server.log" start 
 
Resultado esperado: 
 
servidor iniciado 
 
O que significa: o servidor PostgreSQL foi iniciado usando nosso diretório de dados: 
 
C:\PostgreSQLData 
 
Próximo passo: verificar se o PostgreSQL está aceitando conexões. 
 
2. Verificar o PostgreSQL 
 
Objetivo: confirmar que o PostgreSQL está ativo na porta 5432. 
 
"C:\Program Files\PostgreSQL\18\bin\pg_isready.exe" -h localhost -p 5432 
 
Resultado esperado: 
 
localhost:5432 - aceitando conexões 
 
O que significa: o PostgreSQL está ativo e pronto para receber conexões locais. 
 
Próximo passo: conectar ao PostgreSQL usando o psql. 
 
3. Conectar ao PostgreSQL 
 
Objetivo: abrir o cliente psql e estabelecer uma conexão com o servidor PostgreSQL local. 
 
Execute no CMD: 
 
"C:\Program Files\PostgreSQL\18\bin\psql.exe" -h localhost -p 5432 -U postgres 
 
Resultado esperado: 
 
psql (18.4) 
Digite "help" para obter ajuda. 
 
 
postgres=# 
 
O que significa: entramos no PostgreSQL utilizando o usuário postgres. 
 
Próximo passo: selecionar o banco de dados mercasys. 
 
4. Selecionar o banco MercaSys 
 
Objetivo: sair do banco padrão postgres e entrar no nosso banco de projeto. 
 
No psql: 
 
\c mercasys 
 
Resultado esperado: 
 
Agora você está conectado ao banco de dados "mercasys" como usuário "postgres". 
 
O prompt deverá mudar de: 
 
postgres=# 
 
para: 
 
mercasys=# 
 
O que significa: agora todos os comandos SQL que executarmos serão direcionados ao banco MercaSys. 
 
Próximo passo: consultar as tabelas existentes.
